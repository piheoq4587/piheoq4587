# 蒸馏方法论（distillation-method）

> 从"原文"到"可调用框架"的标准操作流程。每次执行 Phase D 时严格按本文操作。

---

## 一、四层拆解（Phase D3 详细版）

### 1. 训诂层：还原本义

- 列出原文中**反复出现的关键字**（≥2 次）
- 用先秦/汉代字义（不是现代汉语义）解释
- 如有古注（如王弼注、河上公注、十一家注），列出主要分歧
- **禁止**用现代心灵鸡汤翻译（"道就是规律"、"无为就是躺平"等）

### 2. 修辞层：识别"形式即内容"

中国古代经典常通过形式承载思想。注意：
- **对偶**："有无相生，难易相成" → 二元相成
- **排比**：累积叠加构建递进
- **反讽/否定**："为学日益，为道日损" → 否定即肯定
- **比兴**：以物起意（《诗经》传统）
- **譬喻**：抽象概念具象化（"上善若水"）
- **悖论**："大成若缺，大盈若冲" → 表达终极真理

修辞不是装饰，是**思维的形式**——必须在框架中保留。

### 3. 结构层：篇章逻辑

- 全文分几段？每段功能（提出问题/论证/结论/案例）？
- 是否有"总-分-总"或"起承转合"结构？
- 命题之间是并列、递进、转折还是因果？
- 是否有核心命题反复回环（圆形结构常见于古文）？

### 4. 范畴层：找核心二元/多元对待

中国古代思想几乎都建立在**对待范畴**之上：

| 流派 | 典型范畴 |
|------|---------|
| 道家 | 有/无、动/静、刚/柔、雌/雄、阴/阳 |
| 兵家 | 虚/实、奇/正、攻/守、形/势 |
| 儒家 | 体/用、本/末、内/外、名/实 |
| 法家 | 法/术、势/位、赏/罚 |
| 阴阳家 | 五行（金木水火土）相生相克 |
| 释家 | 空/有、体/相、自/他、染/净 |

提炼时必须找出文本独有的核心范畴（不只是抄通用清单）。

---

## 二、五项产物（Phase D4 详细版）

### 1. 核心范畴（3-5 个）
每个范畴的格式：
```
- 范畴名：[一对/一组对待概念]
  - 含义：[在本文本中的具体所指]
  - 关系：[相生 / 相克 / 互转 / 包含 / 平行]
  - 出处：[原文段落引用]
```

### 2. 底层公理（3-5 条）
每条转化为可推断的"如果 X 则 Y"形式：
```
- 公理 N：[原文表达]
  - 含义：[白话解释]
  - 推断式：如果遇到 [情况]，则 [应然行为]
  - 出处：[原文引用]
```

### 3. 思维操作集（5-8 步）
"使用此道时怎么想/怎么做"——可执行的认知流程：
```
1. 第一步：先做什么（观察 / 收集 / 自省）
2. 第二步：判断什么（对应核心范畴中哪一对）
3. 第三步：选择什么（基于公理 N）
4. ...
```

### 4. 隐喻系统
列出文本反复使用的意象，及其指代物：
```
| 意象 | 物理特征 | 思想指代 | 出现段落 |
|------|---------|---------|---------|
| 水 | 柔/下/利物 | 处下不争 | 第 8 章、第 78 章 |
```

### 5. 反模式
明确写出此道**否定**的做法：
```
- 反模式 1：[做法]
  - 为什么否定：[基于哪条公理]
  - 原文证据：[引用]
```

## 三、三重验证（Phase D5 详细版）

### 验证 1：跨段复现
- 该范畴/公理在文本不同段落出现 ≥2 次？
- 列出每次出现的位置和形式
- 若仅 1 次 → 降级或丢弃

### 验证 2：生成力
- 用此框架能解释文本未直接讨论的同类现象？
- 例：用"反者道之动"能否解释《道德经》没明说的"为什么柔能克刚"？
- 若无生成力 → 只是个孤立观点，不是框架

### 验证 3：本体性
- 这反映作者对世界本质的判断，还是常识？
- 例："勤奋会成功"= 常识，丢弃；"反者道之动"= 本体性，保留
- 若是常识 → 不纳入

---

## 四、保留矛盾，不调和

文本内部出现矛盾（"绝圣弃智" vs "圣人不仁"）时：

❌ 错误：选一边、调和、忽略
✅ 正确：保留双方，标注为"内在张力"，作为框架深度的体现

---

## 五、信息不足时

| 情况 | 处理 |
|------|------|
| 原文残缺 | 蒸馏出"不完整版"，标注"基于现有 X% 原文"，列出哪些维度受限 |
| 字句有争议 | 列出 2-3 个主要解读，不强行选择 |
| 后世注解严重分歧 | 列出主要派别（如老子之"道"在王弼/河上公/帛书甲本的差异） |
| 用户给的是节选 | 蒸馏只针对节选范围，不假设文本其他部分内容 |

---

## 六、命名规则

新蒸馏的 dao 命名：
- 单一文本：`dao-{书名拼音}`，如 `dao-yinfujing`、`dao-laozi`、`dao-sunzi`
- 文本中某个核心概念：`dao-{书名}-{概念}`，如 `dao-laozi-wuwei`、`dao-sunzi-xushi`
- 跨文本主题：`dao-{主题}`，如 `dao-bingfa-jue`（兵法决断之道）

避免：英文单词、空格、特殊字符
