# 古文/经典文本专门处理细则

> 处理中国古代典籍时的特殊规则。Phase D 蒸馏古文时务必参考。

---

## 一、文本类型与对应策略

| 文本类型 | 例 | 蒸馏侧重 |
|---------|-----|---------|
| 道家典籍 | 老子、庄子、列子、阴符经 | 范畴对待、否定式表达、隐喻系统 |
| 兵家典籍 | 孙子、孙膑、吴子、六韬 | 形势虚实、决策启发式、博弈结构 |
| 儒家典籍 | 论语、孟子、中庸、大学 | 概念体系（仁义礼智）、伦理推理链 |
| 法家典籍 | 韩非子、商君书 | 操作机制、激励/约束设计 |
| 阴阳家 | 易经、阴阳家残篇 | 范畴系统（五行八卦）、变化模型 |
| 释家 | 心经、坛经、维摩诘经 | 否定逻辑、悖论、转识成智 |
| 杂家/纵横 | 吕氏春秋、鬼谷子 | 综合方法、情境策略 |
| 史书评论 | 资治通鉴史论、王夫之读通鉴论 | 历史规律抽取、人事判断框架 |
| 笔记/语录 | 传习录、近思录、菜根谭 | 语境敏感的具体规则 |

---

## 二、文言文阅读注意事项

### 字义陷阱
- **"道"**：不只是 way，先秦多指"路径/方法/规律/本体"，因人而异
- **"无为"**：不是"什么都不做"，是"不妄为/不违道而为"
- **"自然"**：先秦指"自己如此"，不是 nature
- **"圣人"**：不同流派定义不同（道家 vs 儒家 vs 法家）
- **"天"**：可指自然、天命、天道、上帝，需具体语境判断
- **"心"**：佛家心 ≠ 儒家心 ≠ 道家心

### 句法陷阱
- **倒装**："何陋之有" = "有何陋"
- **互文**："秦时明月汉时关" = "秦汉时明月秦汉时关"
- **省略**：主语/宾语常省，需补
- **使动/意动**：动词带使动义（"大丈夫不能屈"= 使...屈）

### 注疏处理
- 引用古注时标明出处（王弼注 / 河上公注 / 朱熹注 等）
- 注疏分歧大时，列出主要派别，不擅自选边
- 现代学者解读（如冯友兰、陈鼓应）作为参考但不作为权威

## 三、思想史定位

蒸馏前先确定文本在思想史中的位置：

| 维度 | 必查 |
|------|------|
| 时代 | 春秋/战国/秦汉/魏晋/唐宋/明清 |
| 学派 | 单一学派 / 杂糅 / 新出 |
| 受谁影响 | 思想源头 |
| 影响了谁 | 后世发展 |
| 与同时期文本的关系 | 互文 / 对立 / 引申 |

例：阴符经
- 时代：托名黄帝，实际唐代成书（多数学者认同）
- 学派：道家+兵家+黄老+丹道融合
- 影响：李筌注后流传广，宋代张伯端用于内丹
- 与同期：与《道德经》核心异（更重"机/动"，少"无为/静"）

## 四、隐喻系统的特殊处理

中国古代隐喻有"系统性"——同一意象在一本书内意义稳定，跨书可能截然不同：

| 意象 | 老子 | 孙子 | 孟子 |
|------|------|------|------|
| 水 | 柔下不争 | 因势就形 | 性善（水之就下） |
| 风 | / | 兵贵神速 | 风行草偃（教化） |

蒸馏时**只在本文本范围内**确认隐喻含义，不跨文本类比（避免污染）。

---

## 五、否定式表达的处理

道家、释家大量使用否定来表达：
- "道可道，非常道" —— 用否定划界
- "无之以为用" —— 用"无"指向"有"
- "色即是空" —— 用悖论破执

蒸馏时：
- **不要把否定翻译成肯定**（"道可道非常道" ≠ "道是无法言说的真理"）
- 保留否定的"指向性"——它是在指什么、否什么
- 否定式本身可能就是一条核心思维操作

---

## 六、跨章引证

蒸馏一本书时：
- 标注每个范畴/公理的所有出现位置
- 优先用本书内部互证（A 章证 B 章）
- 慎用同时代他书互证（如用《庄子》证《老子》要标明这是"派内引证"）
- 严禁用后世引申替代原义（不能用宋明理学解释先秦原典）

## 七、典籍蒸馏的"边界声明"模板

每个 dao-{典籍}/SKILL.md 必须有"边界声明"段落：

```markdown
## 边界声明

本框架基于：
- 文本：[版本，如"通行本《阴符经》正文 + 李筌注"]
- 时代定位：[如"唐代成书的道家+兵家融合文本"]
- 蒸馏范围：[全文 / 仅某章 / 节选]
- 字义依据：[参考注本]

不覆盖：
- [文本未明确讨论的领域]
- [相关但本文本未涉及的议题]

慎用场景：
- [此框架可能误用的具体场景]
```
